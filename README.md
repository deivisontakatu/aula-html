# 📚 Curso de HTML

## 🎯 Sobre o curso

Este repositório reúne materiais de apoio para o aprendizado de **HTML**, apresentando os principais conceitos necessários para a criação e organização de páginas Web.

O conteúdo foi desenvolvido de forma progressiva, começando pelos fundamentos da linguagem e avançando para a utilização de elementos, atributos e estruturas de conteúdo.

---

## 🚀 Objetivos

Ao longo do curso, o estudante será capaz de:

- 🌐 Compreender o funcionamento básico do HTML.
- 🧩 Identificar os principais elementos HTML.
- 🏗️ Estruturar documentos HTML.
- 📝 Organizar textos e conteúdos.
- 🖼️ Inserir imagens em páginas Web.
- 🔗 Criar links e navegação.
- ⚙️ Utilizar atributos HTML.
- 📋 Criar e organizar listas.
- 🧱 Utilizar elementos semânticos.
- 🔎 Inspecionar e compreender o código de páginas Web.
- 💻 Desenvolver páginas HTML simples.

---

## 🧭 Conteúdos abordados

| Tema | Principais conceitos |
|---|---|
| 🌐 Fundamentos | HTML, HTML5 e estrutura de documentos |
| 🏗️ Estrutura | `DOCTYPE`, `html`, `body` |
| 🏷️ Títulos | `h1` até `h6` |
| 📝 Textos | Parágrafos e formatação |
| 🔗 Links | Links e endereços |
| 🖼️ Imagens | Inserção e configuração de imagens |
| ⚙️ Atributos | `href`, `src`, `alt`, `width`, `height`, `lang`, `title` |
| 📋 Listas | Listas ordenadas e não ordenadas |
| 💬 Citações | Citações e referências |
| 🧩 Semântica | Organização estrutural do conteúdo |
| 🔎 Inspeção | Código-fonte e ferramentas do navegador |

---

## 💻 Metodologia

O conteúdo é apresentado por meio de uma abordagem prática e progressiva, combinando:

- 📖 Explicações teóricas
- 💻 Exemplos de código
- 📊 Tabelas de referência
- 🔎 Análise de exemplos
- 🧠 Representações visuais da estrutura
- ✅ Checklists
- 🚀 Exercícios práticos

A proposta é permitir que os conceitos sejam estudados e imediatamente aplicados na construção de páginas Web.

---

## 🛠️ Ferramentas

Para acompanhar o curso, recomenda-se utilizar:

- 💻 Um computador
- 🌐 Um navegador Web
- 📝 Um editor de código
- 🔧 Git e GitHub, quando aplicável

Um editor como o **Visual Studio Code** pode ser utilizado para escrever e organizar os códigos HTML.

---

## 🧪 Prática

Durante o aprendizado, recomenda-se:

1. 📖 Ler a explicação do conteúdo.
2. 💻 Reproduzir os exemplos apresentados.
3. 🔎 Observar o resultado no navegador.
4. 🛠️ Modificar os exemplos.
5. 🧠 Analisar o comportamento dos elementos.
6. 🚀 Desenvolver os exercícios propostos.

> 💡 **Dica:** não apenas copie os exemplos. Experimente alterar textos, atributos, elementos e estruturas para compreender como o HTML funciona.
