# Aula 03 — Frameworks Front-end

## 1. O que são frameworks front-end?

Um framework front-end reúne ferramentas, bibliotecas e convenções que ajudam a estruturar e padronizar o desenvolvimento de interfaces web.

### Sem framework

- Maior quantidade de código manual.
- Repetição de lógica.
- Maior dificuldade de manutenção.
- Estrutura menos padronizada.

### Com framework

- Componentes reutilizáveis.
- Organização do código.
- Gerenciamento de estado.
- Atualizações eficientes da interface.
- Maior facilidade para aplicações complexas.

## 2. Principais características

### Estrutura organizada

Frameworks estabelecem uma estrutura que facilita a separação e organização dos arquivos e responsabilidades.

### Componentização

A interface é dividida em componentes independentes e reutilizáveis.

### Programação reativa

A interface pode ser atualizada automaticamente quando o estado da aplicação é alterado.

### Build e bundling

Ferramentas do ecossistema podem:

- Transpilar código.
- Minificar arquivos.
- Combinar recursos.
- Preparar a aplicação para produção.

### Rotas

Frameworks e bibliotecas permitem organizar diferentes páginas e views, inclusive em aplicações SPA (*Single Page Application*).

### Integração com APIs

Facilitam o consumo de serviços externos e a sincronização dos dados apresentados na interface.

## 3. Exemplos estudados

| Tecnologia | Característica principal |
|---|---|
| **React** | Biblioteca flexível e baseada em componentes |
| **Angular** | Framework completo com TypeScript e CLI |
| **Vue** | Framework progressivo e de aprendizado acessível |
| **Next.js** | Framework baseado em React para aplicações web mais completas |

## 4. Ideia central

> Frameworks não substituem os fundamentos de HTML, CSS e JavaScript. Eles fornecem uma estrutura para desenvolver aplicações maiores, organizadas e reutilizáveis.
